# Six-input monotone equivalence

Registers the previously orphaned local monosix.py generator. The pinned
template is the publicly merged L_meta_13175.lean (Apache-2.0, upstream
license included). The existing solver finds a monotone witness and screens
a conditional lower bound with free negations. C screening is not a Lean
receipt. No lease, network, or Lean execution occurs here. The ordinary
publisher remains the only route for complete held proof candidates.

For fast posting, the new monotone witness constructor recursively factors
truth tables by cofactors, tries dual decompositions and residual monotone
closures, and ranks formulas by distinct DAG gates. It independently checks
all 64 rows. Only then does the existing bounded C live-set search screen
a conditional lower bound; a longer background budget may try improving
the witness via SAT. This avoids requiring a minimum monotone circuit.

Measured on billy-dev (2026-11-28): the synthetic six-input conjunction
produced a static-valid 27 KiB candidate. A six-file historical sample
(L-meta-13175, 39555, 40311, 39007, 39709, 37479) generated static-valid
candidates for 13175, 40311 and 39007 in 2.52, 3.38 and 3.43 seconds.
The remaining three explicitly refused under the 12-second budget.
These are source-generation results, not kernel checks or credits.
