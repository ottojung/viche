For the government decision, recorded enactment history does not cure the current tally-integrity failure, and a failed current rerun alone does not prove the historical vote invalid. The sample therefore distinguishes a specific host finding from unassigned work and distinguishes code landing from verified deployment.

Judiciary operations successfully froze and identified this distinct four-case cycle, inspected live board state, fetched a sampled remote branch independently, and filed a verdict for every case. Limits include no independent authentication of the execution host beyond issue dispatch/host instructions, no live deployment check, and a dirty canonical checkout that prevented safe publication there. The watchdog's aggregate counts are signals, not a clean bill or a guilt verdict. No policy or measurement-system reform is proposed here; these findings and limitations are submitted for legislative consideration.
